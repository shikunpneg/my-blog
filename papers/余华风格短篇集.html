余华风格短篇集

五篇冷峻隐忍风格的短篇故事

1. 稀粥

场景：饥荒年代，村里的女人煮了一锅稀粥
人物：a1 = 村里的女人，a2 = 她的孩子，a3 = 邻居

饥荒年代，村里的女人煮了一锅稀粥。那是冬天里的一天，她们坐在坑道一样的灶间熬了一个下午，然后在晚饭前一拥而上将稀粥喝下去了。到了夜里，这二十来个女人全都睡意蒙眬。她们的孩子都在外屋睡觉，于是就传来了噼噼啪啪的声响，就像是一颗颗炸弹在他们肚子里爆炸。到了第二天早晨，当那群孩子全部醒来后，发现稀粥已经很久以前就被雨水淋过了，它们看上去如同雨水一样浑浊难以下咽。孩子们嗷嗷乱叫着向他们的母亲求救，于是乎“粥”的欢呼声响遍全村。饥饿吞噬了那些孩子，他们在那个寒冷的清晨伸出颤抖的嘴巴，纷纷咬住了那浑浊的稀粥。然而不多时候，所有的孩子都放下了碗，他们抬起头惊恐地看着对方，仿佛要判断谁才是真正的罪魁祸首。随后他们转身逃出了屋子，在雪地里坐了下来，看着日出的光芒怎样使白雪一片通红。他们中间年龄最小的一个说道：连水都没有啊。另一个立刻反驳：“还不都是因为你。”被饥饿弄得精疲力竭的孩子们，此刻只能以同样的饥渴去寻求同类的理解。这时候两个年龄较大的男孩站了出来，他们开始回忆往昔的日子，那时候他们的父亲能够带他们到城里去买糖果。这些孩子的目光闪闪发亮，他们讲述时的表情让人想起教堂里悬挂的天使雕像，可是当他们的父亲说完往事以后，生活便变得奢侈无比了。他们吃进了糖，还吃进了棉花糖。他们说有一次甚至吃到过一个玻璃纸包着的鸡蛋黄，说是又香又嫩。现在呢？现在他们感到比任何过去都要糟糕，因为什么都没有了。“没有食物”，这个简单的答案却成了两兄弟的败类哲学，让他们在灾难来到时依然趾高气扬。“没有食物，”他们喊叫起来，“就没有我们。”饥饿并没有得到控制，它只是暂时躺下休息一下。接着继续前行时，来到了一座寺庙跟前，一群和尚正站在那里议论纷纷，一个名叫光头的和尚显得特别激动，他大声说：“今天轮到我送斋啦！”意思是明天就可以自由自在无忧无虑的生活了。

2. 葬礼

场景：小镇上的葬礼，死者是一个孩子的父亲
人物：a1 = 孩子，a2 = 孩子母亲，a3 = 邻居

小镇上的葬礼，死者是一个孩子的父亲。那个孩子生前最亲密的朋友——哑巴，也参加了今天的葬礼。他在昨天就已经知道了今天发生的这一切，他没有参加昨天傍晚的聚会，而是回到了家中。当他再次打开抽屉时，看到了一把崭新的剪刀。这把剪刀是他儿子生前用来修理自行车的，他知道儿子喜欢这把剪刀，所以他就将它取了出来。他看到放在墙角的一小堆火化纸，便从里面拿出了一张一张地放进了提着的塑料袋里，这样就减轻了它的重量。然后他重新关上了抽屉，坐在了沙发上。现在他的眼前出现了那辆崭新的永久牌自行车，车轮还在闪闪发亮。他站起来，走到窗口，将头伸出窗外，看着自己的房屋，房子显得阴森可怕，所以他立刻转身回到屋内。这时候已经黄昏了，在昏暗的灯光下，他穿上了那套黑色的衣服，那是他妻子给他买的。穿上后他感到身体沉重了许多。接着他走到儿子的房门前，敲响了他的房门，一个女人的声音在里面询问他是谁？于是他就告诉她是丈夫回来了，并且把他手里提着的塑料袋递了过去。“是剪刀吗？”他点点头，“还有别的什么吗？”“没有了。”他说着走进了自己的房间，脱下了身上的衣服，躺在了床上。他想再看看儿子，但是光线太暗，他看不到儿子的模样，只看到床单上有些汗津津的亮迹。这时他已经睡意朦胧了，可他又听到了一种声音，仿佛是谁正在打呵欠似的，那声音是从远处飘来的。因此他就爬起来，来到楼梯口，沿着楼道走下去。他来到了隔壁的房间里，有一盏电灯在闪烁着微弱的光芒。他透过门缝看到了他们，他们此刻正坐着谈话，他们在说着他儿子的事，声音很小，可是却很感人。后来他轻轻地关上门，又走到楼下的影剧院旁，那时有一个姑娘站在那里，她身穿一件天蓝色的衣裤，正在等待丈夫下班归来。她的眼睛望着马路对面的街道，而她的脚丫则踩在石板路上。他走上去对她说：“你为什么不回家去？”但她并不回答，只是抬起脸来，用她的眼睛看他。

3. 病房

场景：医院的走廊里，一个男人的妻子刚去世
人物：a1 = 丈夫，a2 = 医生，a3 = 护士

医院的走廊里，一个男人的妻子刚去世。他妻子是被煤气中毒窒息而死的。他是这个家庭的唯一男性，因此他也失去了妻子留下的全部财物，只留下一些简单的衣物和日常用品。他的朋友来到时，他已经将那些物品装进了两只编织袋，准备搬回家去。然而他看到朋友们又来了几个人，于是他就知道他们的来意了。他们要他同意他们拆下墙上的暖气片，并且由他们负责更换成液化气灶具。这是煤气中毒事件后的一项新规定，凡是安装有暖气的家庭都要拆下暖气换上液化气灶具。理由很简单，在煤气泄漏事故尚未杜绝的时代，所有的用户都应该学会自救的方法，而液化气灶具比暖气更加易于自救。虽然他的妻子已经死去，可他并不愿意换上液化气灶具。因为他在家里养过一头小猪，这头小猪就是在这里生出来的。所以他说：我不愿把它们拿走。他们说既然不愿拿走，就不拆了。然后就问：“你同意了吗？”他回答：“没有。”“那么，”他们对视一眼，“你就只有搬家了。”这时候他的邻居也来到了，而且带来了一台彩电。他觉得应该拒绝他们的好意，但他不想跟他们争吵。因为他知道一旦吵起来，他们可能会拆掉暖气，而且还会将电视搬到他家来。这样他就连一台电视都看不成。所以他只好让他们坐下，对他们说：我知道你们的意思，可是我不会看电视的。他们这时才坐下来。他们告诉他，现在人们的生活水平提高了，大家都有了自己的汽车，家里还有微波炉什么的，但是谁也不会每天都在家里吃饭，谁都会经常带着家人到饭店去吃一餐饭，所以谁也不会天天在家看电视了，而是天天抱着电脑去上网冲浪了，而且一天都不想离开电脑半步。接着他们问他：是不是也想拥有这些？他说：当然想。他们说：那就要花钱啦！他听后沉思了一会儿，然后说：我现在没钱。他们立刻明白了，就说：那就以后有钱了再买吧。他点了点头说：好的。但他们还不肯走，他们说：你现在还不能决定，总要给你些时间嘛。他就站起来说：我要去医院开个证明，证明我现在没钱，证明明天也还是没钱，证明后天仍然没钱。他们问：为什么？他说：因为我妻子死了。然后他就走了出去。他们互相看了看，摇了摇头，说道：这个人真是没出息。第二天早晨他又来了，他们依旧让他明天不要拆暖气，他还是告诉他们，他知道自己的意思是不同意，但为了面子，他还是要答应。他们又给他出了另一个主意：先拆了暖气再买液化气灶具。他说：我现在没钱，我也没有力气去卖血，我也没有能力去做个体生意，更没有机会去赌博，我想想我除了没钱以外，别的什么都没有。他们听完以后笑了起来，他却显得很认真，他向他们保证：今天晚上他就会想办法弄到一百元钱。到了傍晚的时候，他确实弄到一百元钱了。他兴高采烈地将钱递给他的朋友，让他的朋友放心大胆地把暖气拆了。可是不久之后，他发现他们并不是真心让他明天不要拆暖气，只是想在他身上打几个洞罢了。于是他就非常生气，他对他们说：我不是乞丐，我是富有的绅士，我不要任何人来替我把钱赚了，我会亲自把自己弄富有的。

4. 工地

场景：工地上的工人们吃午饭
人物：a1 = 工头，a2 = 年轻工人，a3 = 老工人

工地上的工人们吃午饭了。他们的脚手架和水泥搅拌机已经撤去，只有他们还在拼命干活。他们在阳光里挥汗如雨，在阴天里满身灰尘。福生站在水泥仓库的屋顶上，看着他们从脚手架上一队队钻过去，又从另一端的脚手架上钻过去。他看到那些脚手架连接起来像蜈蚣的腿一样。然后他们扛着工具走去了，一个年轻的女子在后面追赶他们，喊叫什么“鞋”之类的话，她边追边喊边脱自己的皮鞋扔向他们，有人嘻嘻笑着将她的皮鞋捡起来往回扔。于是她更加得意地喊叫：“谁也不来收你的皮鞋啦！”她一路喊叫跑到他们的脚手架下，跳上去骂道。那几个年轻人哈哈大笑，那个穿着背带裤的年轻人还踢开了她的皮鞋。福生问石头，是不是要再盖几幢房子，石头说还要再盖十幢二十幢三十幢这样的房子，福生知道这是多少间平房，他说十幢房子就是一百间平房，三十幢是三百间，二十幢是二百间，他还问石头要不要四百间？石头摇摇头说太多了，福生就说先盖一百间吧，石头连连点头同意，福生就告诉石头，要给新盖的房子也安装上下水道，这样工人洗了澡倒干净的水时就可以倒到楼下去了。石头听后连连点头，心想这个福生不仅是个有钱人，还是个有见识的人，知道现在城里人都喜欢卫生。两个人说着说着来到了一座桥上，福生对石头说这里风景好，石头觉得这里确实风景优美，就是在心里暗暗吃惊，这个福生怎么这么会说话，一句话就能把石头说动了。两个人坐在桥栏上吃起了午饭。石头吃了两口就要去看看10，福生正埋着头吞口水吃得快极了，石头看了几次都没看住自己，赶紧去看一眼10，这小子低头咬了一口还没咽下去，就飞快地擦了一下嘴巴，扭回头来了。石头吃完了饭站起来要走了，福生还没有把最后一口吃完。这时石头发现不远处有一群麻雀在飞舞，那情景很像是打仗，飞来飞去呱呱乱叫叽叽喳喳，一群麻雀弄出来的声音比飞机轰炸过来的声音还要响亮，让石头毛骨悚然。于是石头转身对福生说：“我们别在这里吃饭了。”10抬起头看看正在消失的夕阳，说：“我还没吃够。”“没意思啦，”石头说，“这太阳都掉下来了。”10这才慢慢地放下碗筷，跟着石头走了回去。福生跟在石头身后，两人一前一后沿着江岸走去。福生走在左边，石头走在右边，石头左手提着一只公鸡，右手拉着那只母羊。公鸡在石头左手手里显得十分沉重，石头一直低着头走路。福生走在右边的时候仰脸看着天空，他的头发被风吹得飘飘扬扬，他的双眼眯成了一条缝，风把树叶吹得沙沙响，还有远处河水流动的声音，还有嘈杂的人声和汽车马达的声响，以及无数种福生听不懂的语言在风里此起彼伏，好像是一只巨大的机器正在运转。

5. 月台

场景：火车站的月台上，母亲送儿子出远门
人物：a1 = 母亲，a2 = 儿子，a3 = 送行的人

火车站的月台上，母亲送儿子出远门。此刻他们已经分手了。母亲将目光从儿子身上移过去，她看到了远处的月台是那么宽阔，上面站着一队站务员。然后她的目光又回到了儿子身上。儿子正低头望着自己的脚，他没有看到母亲的存在，他的头颅低垂着，在月台的水泥地上，有一摊血泊，四周还有一些鲜红的血滴，这些像是某一个下午洒出来的清凉的水珠。父亲也坐在月台的水泥地上，他的头颅也被压下去了一样，他也像刚才那孩子一样，看着自己的双脚，也许他已经看了很久了。他旁边躺着一条小狗，有几根牙齿脱落的小狗骨头躺在不远的地方，还有两片狗皮和一些狗毛。这情景似乎是昨天傍晚的模样，只是少了两条腿，昨天那四条腿正在一堆垃圾里招摇着它们。现在一切都显得安静下来，只有母亲的脚步声还在杂乱地响着，而且越来越弱，最后消失不见了。于是父亲闭上眼睛也睡去。不久之后月台上一片漆黑无声，只有风在吹拂着那些衣服招展而去。凌晨的时候，所有的人都睡意蒙松地来到了。那时候母亲还在路上，火车将在半途把儿子拉走，所以母亲此刻还没有回家，可是车站的月台依然亮着灯。一直守候到深夜的父亲在那一刻睁开了眼睛。他看出了月台上的灯什么时候就要熄灭，所以他决定立即起身离去。那时月台另一端有几个站在那里说话的女人，她们的声音十分遥远，仿佛是浮在空中似的。母亲就在这几个女人的身后，母亲回来时的声响将会打断她们的谈话。因此父亲起床离去，就是为了让母亲最先抵达家中的时候，不会遇上那些女人。父亲穿上衣服以后就走了出去，他在黑暗里无声地走到了月台尽头，然后站住脚朝里面张望，但是什么都看不见。他就沿着栏杆往回走去，走过那边的一块空地后，他又站住了脚。那个时候有两个男人和一个女郎在那里说笑。他发现那个女郎的脸有些像翠花，但他没太在意。他走到近旁时听到男人们都在称赞这个女郎，有一个男人还伸手指向她喊道。这时候他才确定刚才见到的就是翠花。他立刻明白过来她为什么在这里了，因为她被抢走了未婚夫。那时候那个女郎已经扭过脸来了，他看清她的双眼肿胀得厉害。她可能是在哭泣之前突然摔倒的，她仰躺在地下，一只手支起身体，另外一只手撑住地面。她的头发披落在胸前，她的眼睛紧闭着，嘴巴却是张开的，她的嘴唇挂在脸上，仿佛她正在流眼泪，或者她刚刚擦干眼泪。他想当初也是这么一副模样。那时他正要去找栓柱，也就是去找那个叫翠花的女子，因为她在街上骂了他，可他没想到会在这里遇到她。
